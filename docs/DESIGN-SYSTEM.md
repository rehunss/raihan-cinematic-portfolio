# The Architecture of Ideas

The site uses a single environment and a linear route with eight camera stops. At each stop, a small editorial caption establishes the human scale against the structures. Compact navigation and an unobtrusive position rail stay available while scrolling.

| Element | Treatment |
| --- | --- |
| Arrival and discovery | Midnight teal, cold concrete, cyan seams and blue haze |
| Exhibits | Teal broadcast wall, mauve ribbed pavilion and blue technology rack |
| Transformation and impact | Copper courtyard followed by moss and mineral tones |
| Departure | Low-saturation skyline in pale fog |
| Editorial type | Geist in sentence case for names and captions, monospace for numbering and provenance |
| Reading layer | High-contrast HTML, linear headings, details, tables and linked proof |
| Motion | Continuous scroll-to-pose mapping, stop on release, reversible construction changes |
| Reduced motion | Original scene renders, native navigation and the reading index |

The scene uses tapered and beveled concrete, shader grain, etched insets, translucent glass and selectively illuminated seams. Each exhibit incorporates an approved portfolio sample. Fog and changing key-light colors connect the zones. The case overlay keeps focus within a native dialog and returns to the exhibit link.
